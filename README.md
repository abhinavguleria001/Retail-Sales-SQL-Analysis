# Retail Sales SQL Analysis

## Project Overview
This project analyzes retail sales data using MySQL.

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## Dataset
Retail sales dataset containing orders, products, pricing, quantity, discounts, and regions.

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- JOIN
- Views
- Window Functions
- RANK()
- DENSE_RANK()

## Key Business Insights
- Total Revenue
- Top Selling Products
- Monthly Sales Trend
- Revenue by Region
- Revenue by State
- Category-wise Revenue
- Average Discount
- Product Ranking
